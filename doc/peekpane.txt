*peekpane.txt* Local file previews in your terminal

SETUP                                                    *peekpane-setup*
  require('peekpane').setup({display='split', split='right', size=0.5,
    follow_cursor=true, cmd='peekpane', css=nil, filetypes={}})

DISPLAY                                                  *peekpane-display*
  display='split'  Side-by-side preview (default).
  display='toggle' Fullscreen editor/preview switching using tmux window zoom.
                  Alt+P or :PeekFocus switches views. :Peek close restores
                  the previous layout. Other tmux panes are hidden while zoomed.

COMMANDS                                                 *peekpane-commands*
  :Peek [open|close|toggle] [left|right|up|down]
  :PeekScroll [line]
  :PeekFocus
  :PeekZoom

Save a buffer once before opening. Changes are sent after a 150ms debounce.
No editor keymaps are installed. Example:
  vim.keymap.set('n', '<leader>mp', '<cmd>Peek toggle<cr>')

Run npm ci in the checkout. A plugin manager may use build="npm ci".
Set cmd={"node", "/path/to/peekpane/bin/peekpane.js"} to use the bundled
CLI directly. npm link additionally enables the global terminal command.
Only trusted local files should be opened. See README security limitations.
